1) Метод запроса OPTIONS
Описание:

OPTIONS — это HTTP-метод, который используется для получения информации о доступных методах и параметрах взаимодействия с сервером.
Он не выполняет реальных операций (не изменяет данные).
Когда вызывается:

Браузер автоматически отправляет OPTIONS при CORS-запросах (кросс-доменных запросах), если они считаются предварительными (preflight request).
Может использоваться клиентами или API-инструментами для определения поддерживаемых методов перед отправкой запроса.
Что передаёт и принимает:

Передаёт:
Запрашиваемый ресурс (URL).
Заголовки CORS (например, Access-Control-Request-Method).
Принимает:
Список доступных методов (Allow: GET, POST, OPTIONS).
Разрешённые заголовки и источники (CORS).

Пример запроса:
OPTIONS /api/data HTTP/1.1
Host: example.com
Access-Control-Request-Method: POST
Access-Control-Request-Headers: Content-Type

Ответ сервера:
HTTP/1.1 204 No Content
Allow: GET, POST, OPTIONS
Access-Control-Allow-Origin: *
Access-Control-Allow-Methods: GET, POST, OPTIONS

2) HTTP 3.0 - Ключевые особенности
Что нового в HTTP 3.0?

Основан на протоколе QUIC вместо TCP.
Использует UDP для быстрой передачи данных.
Меньшая задержка благодаря мультиплексированию (нет блокировки из-за одного медленного запроса).
Шифрование по умолчанию с TLS 1.3.
Устойчивость к потерям пакетов, что улучшает производительность.

Где используется?
Google, YouTube, Facebook, Cloudflare уже активно используют HTTP/3.

3) AbortController и кейсы применения
AbortController — это объект, позволяющий отменять асинхронные операции (например, fetch()).

Пример:
const controller = new AbortController();
const signal = controller.signal;

fetch('https://jsonplaceholder.typicode.com/todos/1', { signal })
  .then(response => response.json())
  .then(data => console.log(data))
  .catch(err => console.log('Запрос отменён:', err));

setTimeout(() => controller.abort(), 100); // Отменяем запрос через 100 мс

Где применяется?
Отмена HTTP-запросов (fetch).
Остановка таймеров и анимаций.
Отмена операций в Web Workers.


4) Temporal Dead Zone (TDZ)
TDZ — это период, когда переменная объявлена, но её нельзя использовать.

Пример:
console.log(x); // ReferenceError: Cannot access 'x' before initialization
let x = 10;

Объяснение:
let и const не поднимаются (hoisting) как var.
Код не может обращаться к x до её объявления.
